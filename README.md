An open-source, reproducible, and ethically grounded Python library for **Deori** (also *Deuri*; native name *Deori Cchu*; ISO 639-3: `der`, Glottolog: `deor1238`), an endangered Tibeto-Burman language spoken in Upper Assam and Arunachal Pradesh, India.

---

## Mission & Goals

The `deori` library is engineered to serve three distinct groups:
1. **Community Members & Language Learners**: Transparent, accessible tools for transliteration (Assamese script $\leftrightarrow$ Roman community orthography), text normalization, and lexical lookup.
2. **Linguists & Field Researchers**: Grounded data models following Leipzig Glossing Rules, historical source provenance (e.g. W. B. Brown 1895, Louis Jacquesson 2005, Deori Sahitya Sabha), and dialect differentiation.
3. **NLP Developers & Computational Linguists**: Strongly typed (`mypy --strict`), high-performance, pip-installable APIs for tokenization, normalization, and linguistic analysis.

---

## Ethical Principles & Data Integrity

We operate under strict ethical guidelines (see [DATA_ETHICS.md](DATA_ETHICS.md)):
- **Zero Hallucination**: No word, morpheme, rule, or example is ever fabricated or generated by speculative AI models. Every form carries provenance (`source`, `page`, `year`, `variety`).
- **Community Authority**: We actively consult and defer to native speakers and the **Deori Sahitya Sabha (দেউৰী সাহিত্য সভা)**. This library is a computational assistant, not an authority over native speakers.
- **Dialect Respect**: Dialect variety is recorded on every data point. The four primary historical divisions—**Dibongiya (দিবঙীয়া)**, **Tengapaniya (তেঙাপনীয়া)**, **Borgonya (বৰগঞা)**, and **Patorgonya (পাতৰগঞা)**—are respected and preserved without forced harmonization.

## Quickstart & Core API

### 1. Unicode Normalization
Clean non-standard input, enforce Unicode NFC, and handle Assamese-specific characters (e.g., correcting erroneous Bengali *ro* `র` to Assamese *ro* `ৰ` and *wo* `ৱ`):

```python
import deori

# Bengali ro (র) normalized to Assamese ro (ৰ)
clean_text = deori.normalize("দেউরী")
print(clean_text)  # "দেউৰী"
```

### 2. Bidirectional Transliteration
Transliterate between Assamese script and Roman community orthography:

```python
import deori
from deori.models import Script

# Roman Community -> Assamese Script
result = deori.transliterate("cchu", src=Script.ROMAN_COMMUNITY, dst=Script.ASSAMESE)
print(result.target_text)  # "চু"
print(result.confidence)   # 1.0

# Assamese Script -> Roman Community
result = deori.transliterate("দেউৰী চু", src=Script.ASSAMESE, dst=Script.ROMAN_COMMUNITY)
print(result.target_text)  # "deuri chu"
```

### 3. Word & Morpheme Tokenization
Tokenize text with punctuation and whitespace handling:

```python
import deori

tokens = deori.tokenize("দেউৰী চু শিকিবায় নিজিচ্ছা")
print(tokens)  # ['দেউৰী', 'চু', 'শিকিবায়', 'নিজিচ্ছা']
```

### 4. Working with Provenance Data Models
All linguistic records strictly encapsulate bibliographic provenance and dialect variety:

```python
from deori.models import SourceCitation, LexiconEntry, Variety

citation = SourceCitation(
    author="W. B. Brown",
    year=1895,
    title="An Outline Grammar of the Deori Chutiya Language",
    page=65,
    license="Public Domain",
)

entry = LexiconEntry(
    id="der_brown_001",
    deori="cchu",
    deori_assamese="চু",
    deori_roman="cchu",
    pos="noun",
    gloss_en="language, speech",
    variety=Variety.DIBONGIYA,
    source=citation,
    confidence=1.0,
)

print(f"{entry.deori} [{entry.variety.value}]: {entry.gloss_en}")
# cchu [dibongiya]: language, speech
```

## Command Line Interface (CLI)

The library installs a convenient command-line tool `deori`:

```bash
# Normalize Assamese text
deori normalize "দেউরী"

# Transliterate Roman to Assamese
deori translit "cchu" --src roman --dst assamese

# Transliterate Assamese to Roman
deori translit "দেউৰী চু" --src assamese --dst roman

# Look up words in the lexicon
deori lookup "cchu" --to en

# Interlinear glossing
deori gloss "Á mè yó higaye"
```

## Repository Structure

```text
deori/
  orthography/   # Script detection, Assamese-Roman transliteration, NFC normalization
  phonology/     # Phoneme inventories, syllable structure, IPA mappings
  lexicon/       # Trilingual lookup, fuzzy search, verified source citations
  morphology/    # Stemming, agglutinative suffix segmenter, rule-driven inflection
  syntax/        # SOV template matching, clause structures
  numerals/      # Counting system and classifiers
  corpus/        # Interlinear glossed texts (Brown 1895, folk narratives)
  translate/     # Rule- and gloss-based translation
  tokenizer/     # Word and morpheme tokenization
  io/            # Importers/exporters (JSON, CSV, CoNLL-U, Anki)
  cli.py         # Command-line interface (`deori lookup`, `deori translit`, etc.)
  data/          # Validated schemas and versioned datasets
tests/           # Pytest unit tests, doctests, and Hypothesis property suites
examples/        # Runnable usage scripts (e.g. quickstart.py)
```
